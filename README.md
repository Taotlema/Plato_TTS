# Plato: Text to Speech App
Open Book Text to Speech Project - Computer Application

## Technologies and Libraries

Plato is built with Python and PyQt6, outsourcing text to speech and speech to capabilities from Kokoro and Vosk.

| Technology | Purpose | Official Source |
|---|---|---|
| [Python](https://www.python.org/) | Core programming language used for application logic and processing. | [Documentation](https://docs.python.org/3/) |
| [PyQt6](https://www.riverbankcomputing.com/software/pyqt/) | Desktop graphical interface, windows, widgets, and application events. | [Documentation](https://www.riverbankcomputing.com/static/Docs/PyQt6/) |
| [Kokoro](https://github.com/hexgrad/kokoro) | Text-to-speech synthesis for generating spoken audio from text. | [GitHub Repository](https://github.com/hexgrad/kokoro) |
| [Vosk](https://alphacephei.com/vosk/) | Speech recognition for processing microphone input and interpreting voice commands. | [GitHub Repository](https://github.com/alphacep/vosk-api) |
